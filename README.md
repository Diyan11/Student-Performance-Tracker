# Student Grade Analyzer

A console-based Python application for managing student records and analyzing their grades.

## Features

- Add students
- View all students
- Search students
- Update student marks
- Delete students
- Calculate individual averages
- Calculate class average
- Find highest average
- Find lowest average
- Automatically calculate grades
- Input validation
- JSON data storage

## Technologies

- Python
- JSON
- File Handling

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

python Student_Grade_Analyzer.py
